# 03 — Cyber Threat Analysis

## Project: Attack Technique Reference Lab

This module documents defensive analysis of common attack categories.

### Network-Level
- Port/network scanning
- Packet sniffing
- Man-in-the-middle concepts
- Denial-of-service concepts

### Web
- Cross-site scripting
- SQL injection
- Directory traversal
- File inclusion

### Host
- Malware
- Privilege escalation
- Brute force
- Phishing
- Data exfiltration

### Analyst Output

For every technique document:

**Attack concept → Observable evidence → Relevant log source → Detection idea → Mitigation**

All demonstrations must use intentionally vulnerable or isolated lab systems.
