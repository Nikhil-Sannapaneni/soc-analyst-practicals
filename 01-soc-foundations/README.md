# 01 — SOC Foundations

## Project: SOC Operations Handbook

### Objectives
- Understand the purpose of a Security Operations Centre.
- Document SOC capabilities, roles and workflow.
- Connect Linux and networking fundamentals to security monitoring.

### SOC Workflow

**Telemetry → Detection → Triage → Investigation → Containment → Recovery → Lessons Learned**

### Common SOC Roles
- Tier 1 Analyst — alert monitoring and initial triage
- Tier 2 Analyst — deeper investigation and incident response
- Tier 3 / Threat Hunter — advanced detection and hunting
- Incident Response — containment and recovery
- Detection Engineer — detection logic and tuning
- Threat Intelligence — external threat context

### Portfolio Evidence
Document one example alert and show how it moves through the workflow.

> This project is educational and does not claim access to a production SOC.
