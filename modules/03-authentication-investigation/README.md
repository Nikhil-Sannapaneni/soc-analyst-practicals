# Module 03 — Authentication Investigation

## Objective

Practise investigating suspicious account activity.

## Investigation Questions

1. Which account was targeted?
2. How many failed attempts occurred?
3. Did a successful authentication follow?
4. Is the source address expected?
5. Is the account privileged?
6. What additional telemetry should be checked?

## Analyst Decision

Do not label activity malicious from one event alone. Correlate authentication events with endpoint, network and identity telemetry.
