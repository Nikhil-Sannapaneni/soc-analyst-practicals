# 10 — Jira Incident Management

## Project: SOC Ticket Lifecycle

### Ticket Template

**Summary:** Suspicious authentication activity

**Priority:** Set from documented impact and confidence.

**Description:**
- Detection source
- First observed
- Last observed
- User
- Host
- Source IP
- Evidence
- ATT&CK mapping
- Actions taken
- Next action

### Workflow

New → Triage → Investigation → Containment → Recovery → Resolved → Closed

### SLA Practice

Record detection time, acknowledgement time, escalation time and resolution time using synthetic timestamps.
