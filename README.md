Hands-on defensive security portfolio for a Junior / Tier 1 SOC Analyst role.

- Security monitoring and alert triage
- Log analysis
- Authentication investigations
- Phishing analysis
- Incident response
- Threat hunting
- MITRE ATT&CK mapping
- Vulnerability management
- Python security automation

## Analyst Method

**Alert → Evidence → Analysis → ATT&CK mapping → Assessment → Response → Detection improvement**

The portfolio is designed to demonstrate practical reasoning and documentation expected from a junior SOC analyst.

All examples are for authorised lab environments and use simulated or non-sensitive data.
