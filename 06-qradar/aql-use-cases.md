# QRadar AQL Use Cases

## Use Case 1 — Repeated Authentication Failures

Goal: identify sources generating unusually high failed-login volume.

## Use Case 2 — Successful Login After Failures

Correlate failed authentication with a later successful event.

## Use Case 3 — Unusual Destination

Review flows for unexpected outbound destinations.

### Documentation Standard

For each query record:
- Data source
- Query
- Time window
- Expected result
- False positives
- Analyst action
