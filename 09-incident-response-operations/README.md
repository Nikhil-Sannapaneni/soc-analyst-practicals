# 09 — Incident Response Operations

## Project: SOC Response Technology Lab

This module connects the existing incident-response project with operational technologies.

### EDR/XDR
Use endpoint telemetry to investigate processes, persistence, files and network connections.

### Wazuh
Practise:
- Agent-based monitoring
- File integrity monitoring
- Log collection
- Rule-based alerting

### SOAR
Automate repeatable response actions such as:
- Enrich an IOC
- Create a ticket
- Notify an analyst
- Isolate an endpoint when an approved playbook condition is met

### Jira
Use a ticketing workflow:

**New → Triage → Investigating → Contained → Resolved → Closed**

### Microsoft Sentinel
Study:
- Log Analytics
- KQL
- Analytics rules
- Incidents
- Workbooks
- Automation rules / playbooks

No production credentials or tenant data should be committed.
